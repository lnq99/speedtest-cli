# Архитектура / How the code works

Весь код — в одном файле `speedtest.py`. Четыре небольшие функции с одной
ответственностью каждая.

## Поток выполнения

```
main()
 └─ parse_args()      # разбор аргументов командной строки (argparse)
 └─ measure()         # цикл из N последовательных запросов
     └─ download_once()   # один запрос + полное скачивание тела
 └─ format_report()   # сборка итогового текстового отчёта
```

## Функции

### `download_once(url, timeout) -> (elapsed, num_bytes)`
Выполняет один `requests.get(url)`. Засекает время через
`time.perf_counter()` (монотонный таймер высокого разрешения) **до** запроса и
**после** чтения `response.content`. Обращение к `.content` полностью
вычитывает тело ответа, поэтому измеренное время покрывает всю загрузку, а не
только время до первого байта. `raise_for_status()` превращает HTTP-ошибки
(4xx/5xx) в исключения.

### `measure(url, n, timeout) -> (total_bytes, total_time)`
Вызывает `download_once` ровно `n` раз **последовательно** (следующий запрос
стартует только после полного завершения предыдущего), по ходу печатает прогресс
по каждому запросу и накапливает суммарные байты и время.

### `format_report(url, n, total_bytes, total_time) -> str`
Считает производные метрики и собирает отчёт:
- `avg_time = total_time / n` — среднее время запроса (секунды);
- `speed = (total_bytes / 1 000 000) / total_time` — скорость в MB/s.

Есть защита от деления на ноль (если `total_time == 0`).

### `main(argv) -> int`
Склеивает всё вместе, ловит `requests.RequestException`, печатает ошибки в
stderr и возвращает код выхода (`0` — успех, `1` — ошибка). Вызывается из
`if __name__ == "__main__": sys.exit(main())`.

## Формула скорости

```
speed [MB/s] = (сумма всех скачанных байт / 1 000 000) / сумма всех времён [с]
```

Это совокупная пропускная способность по всем запросам (а не среднее арифметическое
скоростей отдельных запросов).
